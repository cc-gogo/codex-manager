# Codex 对话管理器：项目目录树浏览

## 目标

将主界面改为接近 Codex 的三栏浏览方式，使用户能按实际工作目录查找对话，而非在完整表格中筛选。

## 布局

- 左栏上方为分类：全部、普通、归档、子代理、幽灵、损坏、重复。
- 左栏下方为项目树，使用每条对话的 `Cwd` 组成工作目录层级。
- 左栏底部固定显示“未归属对话”，收纳 `Cwd` 为空、目录失效或无法推断工作目录的记录。
- 中栏显示当前分类及当前树节点下的对话，使用标题优先、时间和短 ID 辅助的紧凑列表；保留复选框供单条和批量永久删除。
- 右栏显示所选对话的详情、扫描状态与永久删除入口。

## 筛选规则

1. 分类与目录树联动。选中一个分类后，树仅保留该分类下存在对话的项目和文件夹。
2. 选择“全部”时，树展示所有类别的工作目录结构。
3. 选择目录节点时，中栏只显示该目录及其子目录内的匹配对话。
4. 选择“未归属对话”时，中栏只显示没有可用 `Cwd` 的匹配对话。
5. 归档与其他类别相同：归档对话仍按项目和文件夹分组；只有没有 `Cwd` 的归档对话才进入“未归属对话”。

## 数据与安全

- 目录树是内存视图，由已扫描的 `ConversationRecord.Cwd` 生成，不读取、创建、移动或删除用户项目文件夹。
- 只改变浏览与筛选界面，不改变现有永久删除确认、进程守卫和清理逻辑。
- 对话详情继续仅在用户选择一条对话后加载。

## 验收

- 选“归档”后，项目树只保留包含归档对话的目录，且中栏不会出现普通对话。
- 点击树节点后，中栏仅显示该节点范围内的对话。
- 没有 `Cwd` 的对话不会混入真实项目，而在“未归属对话”。
- 可勾选中栏对话，并继续使用原有永久删除流程。
- 主窗口布局测试验证旧“最近对话”区已移除，项目树与中栏绑定存在。
