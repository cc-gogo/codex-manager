# Codex 项目侧栏同步浏览

## 目标

项目区直接使用 Codex 左侧栏保存的项目名称、顺序和会话归属，不显示项目 UUID 或磁盘盘符；项目区底部提供真正可点击的“最近对话”。

## 数据来源

从 `.codex-global-state.json` 读取：

- `local-projects`：项目 ID、显示名称与根目录。
- `project-order`：项目显示顺序。
- `thread-project-assignments`：会话到项目 ID 的显式归属。
- `sidebar-project-thread-orders`：项目内会话的 Codex 侧栏顺序；缺失时按最近更新时间倒序。

项目 ID 仅用于内部关联，界面只显示 `local-projects` 的名称，例如“nextsay”。

## 浏览规则

1. 分类按钮及其现有行为不改变。
2. 项目区按 `project-order` 显示项目；未列入排序的项目按名称追加。
3. 会话优先按 `thread-project-assignments` 分到项目；没有显式归属时，仅当 `Cwd` 在某一项目根目录下时才按路径归属。
4. 项目内可按相对于项目根目录的子文件夹展开；不显示 `C:`、`D:` 或其他磁盘根。
5. 无法归属、项目 ID 不存在或 `Cwd` 无效的记录显示在“未归属对话”。
6. 项目区最后固定显示“最近对话”，包含全量对话中更新时间最新的 30 条；点击后中栏只显示该集合。
7. 选择分类时，项目树、未归属对话和最近对话都只包含该类别的记录。

## 对话列表

- 每条对话固定两行高度。
- 第一行是单行截断标题。
- 第二行仅显示最近时间与短 ID。
- 完整标题仍可通过悬停提示查看，详情继续在右侧按需加载。

## 安全与验收

- 项目元数据仅用于只读分组，不会修改任何 Codex 数据或用户文件夹。
- `nextsay` 等项目名替代项目 UUID；项目区不出现 C/D 盘根节点。
- 长标题不超过两行高度。
- “最近对话”位于项目区最底部，并能筛选中栏内容。
- 归档等分类仍按当前分类逻辑工作，项目与最近对话会随分类联动。
