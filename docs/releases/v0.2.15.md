# Codex Manager v0.2.15

[中文说明](#中文说明)

This release switches the manager's active inventory and detail-reading paths to local Codex data. It does not start a Codex App Server for refresh or conversation details.

## Changes

- Scan local rollout JSONL, SQLite databases, and sidebar state directly. Cloud-only catalog entries are excluded from the local inventory.
- Keep **Recent** in the manager as the no-project conversation group; it does not follow Codex Desktop's cross-project recent-activity view.
- Read full local conversation details for display and Markdown export, including newer event formats.
- Update import, deletion, provider synchronization, and backup handling for newer SQLite schemas. Database backups include uncheckpointed WAL data.
- Block permanent deletion while Codex is running, and improve exit/restart failure handling.

## Downloads

- Windows: `Codex-Manager-Setup-v0.2.15.exe` (includes the .NET runtime).
- macOS Apple Silicon: `Codex-Manager-macos-arm64-v0.2.15.zip`.
- macOS Intel: `Codex-Manager-macos-x64-v0.2.15.zip`.

The macOS ZIPs are **unsigned, unnotarized preview builds produced on Windows**. They have not been tested on physical Mac hardware, and macOS may block them. We cannot claim they work on every Mac; please report launch failures with the macOS version and error message.
ZIP extraction may also omit the executable bit. If necessary, run `chmod +x "Codex Conversation Manager.app/Contents/MacOS/CodexConversationManager.Mac"` in the extracted folder. This does not resolve signing or notarization restrictions.

## Safety

Back up important conversations and fully exit Codex before importing, deleting, or synchronizing local data. This application processes conversation data locally; these operations do not upload conversation content.
